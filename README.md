# DSH QQ Companion

DeepSeek Harness 的 QQ 角色陪伴插件。通过外部 OneBot v11 网关收发消息，DSH 管理后台工作进程；无需另行维护桥接服务。

支持群/私聊白名单、全局成员黑名单、独立会话、主动搭话、来源隔离的 Mnemon 记忆、每日学习与日记、受控技能笔记、群分析、图片和表情。GIF 最多采样三帧。

## 环境与安装

- Node.js 24 或更新；针对 DSH 0.2.1-rc.2 验证。
- 已登录的外部 OneBot v11 网关，WebSocket 与 HTTP 地址、令牌。
- 使用现有模型和工作区人格。插件不附带账号、人设或模型凭据。
- 日记/技能需要兼容的 Mnemon Documents、Skills 来源。QQ 必须被通用 Mnemon 生命周期排除；未通过隔离检查时停止推理。
- 群分析图片需要 Python 3（报告渲染依赖）与可用 Chromium；图片/GIF 处理需要 ffmpeg。

安装发行版 tgz 到 DSH profile，保留宿主提供的 Cordis、tools、scope 实例。独立开发安装使用 `npm ci --ignore-scripts --legacy-peer-deps`，避免旧 API 客户端与新宿主的 peer 版本解析冲突。不要向 QQ preset 添加通用系统、文件、管理或子代理工具。

插件配置可指定 `dataDir`、`legacyConfigFile`、`stateDir`、`workspace`、`selfQQ`。`startEnabled` 仅影响首次初始化，默认关闭。既有桥接配置可一次性导入并保留模型、多模态及记忆配置；切换前必须停止原消费者。新实例先在私有管理配置中设置连接与身份，再启用。令牌不通过网页表单显示。

在 DSH 插件配置中打开管理页，可调整白名单、主动参数、日常整理、日报，添加/解除成员黑名单，读取/下载日记，查看 Token 与审计。群白名单允许该群任何未屏蔽成员 @ 机器人。私聊白名单只控制私聊。

## 默认行为

- 白名单外消息完全忽略；成员黑名单优先。
- 主动机会统一每日10次，每窗口至少30分钟；普通话题插入概率5%，冷群30分钟，私聊2小时，23:00–08:00静默。条件检查在本地执行，不调用模型；实际发起模型回合时扣额度，即使最后保持安静。
- 私聊主动问候后等待真人回应，不连续追问；正常回复不计入主动额度。
- 自动边界：成功提醒后再次出现本人新越界，成功告知之后屏蔽。管理页手动屏蔽立即生效，不发送通知。主人和机器人不能被屏蔽；主人私聊 `/解除黑名单 QQ号` 可解除。
- 默认北京时间00:05整理前一天，只使用允许群的公开样本。有样本时学习、日记和技能筛选合并一次生成；没有样本不调用模型。失败不自动重试，补跑需明确选择过去日期且不覆盖。
- 日记保存于 `workspace/日记/YYYY-MM-DD.md`，并归档 Mnemon Documents。技能使用 Mnemon 原生管理；至少3次真实成功流程才可沉淀。不会训练模型权重或增加工具权限。
- 私聊事实只留原私聊；跨窗口公开事实仍需来源授权。日记正文仅可信管理网页和主人本人私聊明确请求可见。

## 验证与发布

`npm test` 运行控制、界面、权限和独立 worker 测试；`node --test test/legacy/test-*.mjs` 可运行迁移回归（部分需 Python/ffmpeg）。`npm run build` 生成原生 DSH 客户端包。测试网关和模型均为隔离夹具，不发送真实 QQ。

配置更新带修订号，撤权先关闭发送门禁，提交成功后才恢复。连接参数变更需要显式重连；不确定的发送不重试。禁用插件保留业务数据。异常退出留下的 `control.lock` 需确认原进程退出后人工移除；不能盲删活跃锁。
